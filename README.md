# Full Stack Development - Programming Exercise (Blood Donor Registry)

| Folder | Description |
|---|---|
| program-1-browser | HTML, CSS and JavaScript registry (open index.html with Live Server) |
| program-2-react | React app with hooks and React Router (`npm i && npm run dev`) |
| program-3-node-utility | Node.js utility without Express (`npm start`, port 3003) |
| program-4-express-api | Express REST API with JWT and bcrypt (`npm i && npm start`, port 3004) |
| program-5-full-stack | React + Express + Sequelize (`npm i && npm run dev`) |

For program 5, copy `server/.env.example` to `server/.env` and `client/.env.example` to `client/.env`.
